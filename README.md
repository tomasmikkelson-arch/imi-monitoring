# Моніторинг згадок ІМІ

Сайт для звітів моніторингу згадок Інституту масової інформації за вигрузками Looqme.
Працює на безкоштовному GitHub Pages, сервер не потрібен: Excel рахується прямо в браузері.

## Як користуватися

1. Відкрийте сайт і завантажте xlsx із Looqme (аркуш «Статті»).
2. Звіт порахується за кілька секунд: охоплення, теми й тексти ІМІ, типи згадок, тональність, медіа, експерти, висновки, шум і повний реєстр матеріалів.
3. Кнопка **«Зберегти в архів»** записує звіт у папку `reports/` цього репозиторію. Після цього він з'являється на головній у списку «Збережені звіти» і має постійне посилання виду `?r=2026-10-19_2026-10-25`.
4. **«Зберегти PDF»** відкриває друк браузера — оберіть «Зберегти як PDF».

### Доступ до збереження (налаштовує адміністратор один раз)

Запис в архів іде через GitHub API, тому сайту потрібен ключ GitHub. У файлах сайту його немає — він зберігається лише в браузері тих, кому ви дали доступ.

1. Створіть ключ: https://github.com/settings/personal-access-tokens/new → Repository access: **Only select repositories** → `imi-monitoring` → Permissions → Repository permissions → **Contents: Read and write** → строк дії — найдовший доступний → Generate token.
2. Відкрийте сайт → внизу головної «Доступ до збереження» → вставте ключ → «Увімкнути збереження».
3. Там само натисніть **«Скопіювати запрошення»** і надішліть це посилання колегам у месенджері.

Колега відкриває запрошення один раз — і на її пристрої збереження увімкнене назавжди. Далі вона просто завантажує файл: звіт сам зберігається в архів, і одразу з'являється кнопка «Копіювати посилання». GitHub-акаунт їй не потрібен.

Запрошення дає право записувати лише в цей репозиторій, але не публікуйте його відкрито. Коли ключ закінчиться, сайт напише, що ключ недійсний: створіть новий і розішліть нове запрошення.

## Відтворюваність

Той самий файл завжди дає ті самі цифри: правила закриті, без випадковості. Для звірки є блок «Контрольні підсумки» (у т. ч. суми колонок переглядів по файлу і відбиток SHA-256) і перевірка з командного рядка тим самим рушієм:

```
node tools/analyze.js шлях/до/файлу.xlsx
node tools/analyze.js файл.xlsx --json reports   # записати звіт в архів локально
```

## Структура

- `index.html` — сторінка
- `assets/engine.js` — методика: очищення від шуму, згортання дублів, охоплення, теми, типи згадок, тональність
- `assets/app.js` — інтерфейс, архів, збереження на GitHub
- `assets/style.css`, `assets/fonts/` — дизайн (KyivType Sans + Overpass)
- `assets/vendor/xlsx.full.min.js` — SheetJS для читання Excel
- `reports/` — збережені звіти (`index.json` + по файлу на період)
- `tools/analyze.js` — перевірка з командного рядка

Теми (кластери) задано в `THEMES` у `assets/engine.js`: якщо з'явиться новий постійний продукт ІМІ, його можна додати туди одним рядком.
