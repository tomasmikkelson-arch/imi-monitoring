Зберегти звіт в архів

Звіт запишеться в архів сайту й з’явиться в списку на головній з постійним посиланням. Для запису потрібен доступ: відкрийте посилання-запрошення від адміністратора сайту або вставте ключ GitHub — це робиться один раз на пристрої.

Як отримати ключ
  1. Відкрийте github.com/settings/personal-access-tokens/new під акаунтом, який має доступ до репозиторію.
  2. Repository access: Only select repositories → оберіть imi-monitoring.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Натисніть Generate token і вставте ключ нижче.

Збереження в архів на цьому пристрої увімкнено.

Посилання-запрошення для колег

Людина відкриває його один раз — і на її пристрої теж вмикається збереження звітів. Ні GitHub, ні ключ їй не потрібні. Надсилайте лише своїм: хто має це посилання, може записувати звіти в архів.
